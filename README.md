# GiftExchange

My sister wanted to do a completely blind secret santa gift exchange. We found some sites that would
take
the input and generate a list, but that didn't meet the requirements of completely blind because one
person
still had to take the results and send them out. This project was designed to be able to generate the
list
and then automatically email the participants in the exchange with only the person that they were to buy
for. <br>

Over time the exchange changed to where my kids and my nieces and nephews were exchanging gifts. The
main
goal of the revised script was to make sure that it was randomly picked, but to account for the desire
to
weight is towards someone they had not gifted to in a while. <br>

The initial script was written in the matlab scripting language. This version is after it was converted
to
python. <br><br>
